# Mission 06 — Deploy to Vercel

## Goal
Deploy AI Planner so it can be used on mobile and desktop through a public URL.

## Required Steps

1. Ensure app builds locally
2. Initialize git if needed
3. Create GitHub repository
4. Push project to GitHub
5. Deploy through Vercel
6. Confirm the app works on phone browser

## Constraints

- Do not add backend
- Do not add database
- Do not add auth
- Do not add API keys
- Do not change product behavior
- Stop before making unnecessary product changes

## Validation

Before deployment:
- npm run lint passes
- npm run build passes

After deployment:
- Open the Vercel URL on desktop
- Open the Vercel URL on phone
- Add task
- Start task
- Complete task
- Refresh page and confirm localStorage works

## Deliverables

Report:
1. Deployment URL
2. GitHub repo URL
3. Any deployment issues
4. Mobile test result
